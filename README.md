It's important to clarify that **RCControl is not a cheat**. Cheats typically involve modifying game code, giving players an unfair advantage, or breaking the rules set by game developers. This is no different than if you were manually controlling the recoil yourself. It's a simple automation of the repetitive motion that makes recoil manageable.

3. **Compliant with Game TOS**  
   Most games are only concerned with external modifications that manipulate their internal systems or provide players with advantages that cannot be achieved by normal gameplay. Since RCControl doesn’t interfere with any game files or provide an unfair advantage beyond simplifying manual mouse input, it is well within the guidelines of most terms of service agreements.

4. **No Alteration of Game Balance**  
   RCControl does not alter how a weapon behaves, the damage it does, or the hit registration. It simply helps you control the recoil, which is something that is traditionally done by players through skill. In fact, many professional players use their own versions of recoil control, and this tool is just an enhancement of that skill.
